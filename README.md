# Hola, soy Gerónimo Daguerre 👋

**Analista Funcional · en camino hacia Data & BI Analytics**

Vengo del lado funcional/operativo de sistemas de gestión pública y
educativa — donde el trabajo diario es traducir requisitos de negocio en
modelos de datos, detectar dónde falla un proceso y sostener la
integración entre sistemas. Este portfolio documenta esa base y, en
paralelo, el camino hacia un perfil más técnico de **Data Analytics /
Business Intelligence**: SQL avanzado, modelado dimensional, Power BI/DAX,
Python para análisis y NLP.

No busco venderme como algo que no soy: no tengo background de Data
Scientist puro ni de Data Engineer de producción. Lo que sí tengo es
criterio para leer un dataset con desconfianza metodológica antes de
confiar en un indicador, y la costumbre —por el rol funcional— de no
separar el análisis de la pregunta de negocio que lo justifica.

---

## 🧭 Lo que hago

- **Modelado y calidad de datos** — normalización, integridad
  referencial, frameworks de validación entre sistemas.
- **Business Intelligence** — Power BI, DAX, star schema, diseño y
  validación de indicadores compuestos.
- **Análisis exploratorio y storytelling con datos** — Python (pandas,
  matplotlib), narrativas basadas en evidencia, no en gráficos sueltos.
- **NLP aplicado a datos operativos** — topic modeling y análisis de
  sentimiento sobre texto libre (tickets, peticiones).
- **Análisis funcional** — traducir procesos de negocio reales
  (administración pública, sector educativo) a modelos técnicos
  sostenibles.
